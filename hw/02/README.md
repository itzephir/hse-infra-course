# Домашнее задание №2. Развёртывание Kubernetes на bare metal

[К списку заданий](../../README.md)

[Решение: Hard Way, kubeadm и Kubespray](solution.md)

Источник: `Домашнее задание 2.pdf`, 1 страница. Ниже приведено условие задания в Markdown.

Необходимо самостоятельно найти и сравнить несколько способов развёртывания Kubernetes на собственных серверах.

Для каждого выбранного варианта кратко опишите:

- как выполняется развёртывание кластера;
- какая инфраструктура требуется;
- какие действия выполняются автоматически, а какие вручную;
- как создаются control plane и worker nodes;
- основные преимущества;
- основные недостатки и ограничения.

В завершение сравните рассмотренные способы и объясните, в каких условиях каждый из них будет наиболее подходящим.

На защите необходимо кратко рассказать о найденных способах развёртывания, объяснить различия между ними и обосновать свои выводы.
